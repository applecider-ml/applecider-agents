applecider-agents / collaboration

Multi-Agent Transient Discovery

Collaborative multi-specialist system for astronomical transient triage and anomaly verification (ZTF & Rubin LSST).

Design Principle
Every number comes from a tool call; the model never does science.

Overview

With the Vera C. Rubin Observatory generating ~10 million alerts nightly, standalone classifiers that output single probabilities are insufficient for identifying rare transient discoveries (e.g. Kilonovae, FBOTs, SLSNe). Genuine discovery requires verifying host galaxy context, rejecting Milky Way stellar contaminants, checking multi-year archival baselines, and evaluating conformal credibility.

Astrophysical Pitfall Resolution

1. SLSN Over-prediction

In benchmark evaluations, "argmax SLSN" carries only 64% true precision. The system evaluates host photo-z: if implied pseudo-absolute magnitude \(M > -20\), it down-weights priority from 3 to 2.

2. Milky Way Stellar Contamination

Flaring stars or cataclysmic variables can mimic early extragalactic rise. The Context Specialist checks Gaia parallax/proper-motion (>3σ) to definitively reject Galactic contaminants.

3. Nuclear Flaring in Active Nuclei

Stochastic AGN flares often trigger blind anomaly detectors. Broker history (>365 days span) and WISE colors (\(W_1 - W_2 > 0.8\)) correctly classify the source as persistent AGN.

4. Out-of-Distribution Candidates

When credibility drops (< 0.05) and the 1% blind consensus alarm fires on an unclassified source with clean history, the Lead Scientist escalates to Priority 3 for Target of Opportunity (ToO) follow-up.
